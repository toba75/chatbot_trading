# CLAUDE.md

Avant toute action dans ce dépôt, lis `AGENTS.md` et applique-le : c'est la
seule gouvernance normative. Ses règles priment sur toute habitude par défaut,
notamment :

- lecture seule pour l'analyse, modification uniquement sur demande explicite ;
- aucun commit, push ou pull request sans demande explicite du développeur ;
- revue contradictoire en contexte vierge pour tout diff ou toute réponse non
  triviale ;
- vision utilisée réellement pour vérifier ce qui se contrôle visuellement, et
  question au développeur en cas de doute persistant ;
- travail en français avec une accentuation correcte.

`PROCESS.md` décrit le pipeline réellement construit ; `docs/plans/` porte les
tranches en cours, chaque plan étant l'autorité d'exécution de sa tranche.
